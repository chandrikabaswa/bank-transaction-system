# 🏦 Bank Transaction System

A simple *Java console application* that simulates basic banking operations like deposits, withdrawals, and payments — built using Object-Oriented Programming (OOP) principles.

## 📂 Project Structure
- *p1, p2, p3, p4:* contain different classes for validation, transactions, and main logic
- *module-info.java:* Java module configuration
- *.classpath & .project:* Eclipse configuration files

## 💡 Features
- User PIN validation  
- Deposit and withdrawal functions  
- Secure and modular structure using multiple classes
